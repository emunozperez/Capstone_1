# Capstone_1: New Jersey In-Store Sales Analysis

## Project Overview

This capstone analyzes in-store sales in **New Jersey** using the sample
sales database provided for the Year Up United Data Analytics Training
Academy. The project uses SQL to explore sales performance and Excel to
summarize and visualize the findings.

The goal is to understand revenue trends, compare New Jersey performance
with its region, evaluate product category performance, and identify
store-level opportunities for the next quarter.

## Territory

-   **Sales territory:** New Jersey
-   **Sales channel:** In-store sales
-   **Regional grouping:** Northeast

## Dataset and Tables

The analysis uses the `sample_sales` database created from
`sample_sales.sql`.


## Analysis and Deliverables

The SQL analysis includes:

-   New Jersey total revenue
-   New Jersey sales date range
-   Monthly revenue trends
-   New Jersey versus Northeast revenue
-   Monthly category sales-record count and average sale amount
-   Store revenue ranking

The Excel workbook contains summary findings, query results, charts, SQL
query references, and notes on metric interpretation.

## Tools

-   **MySQL / MySQL Workbench:** Database setup and SQL analysis
-   **Git / GitHub:** Version control and project repository
-   **Microsoft Excel:** Data export, analysis, and visualization
